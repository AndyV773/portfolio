Django

How to install and set up Django

  1. Ensure Python and pip are installed. If not installed Download Python, or install PyEnv-Win.

    SHELL

    Copied!

    
python --version
pip --version
  2. In you project folder activate a virtual environment (recommended) Virtual Environment (venv)
  3. Install Django

    SHELL

    Copied!

    
pip install django
  4. Verify installation

    SHELL

    Copied!

    
django-admin --version
  5. After installing Django you can create a project. Replace 'myproject' with whatever name you like.

    SHELL

    Copied!

    
django-admin startproject myproject
  6. Use the cd command to change your current location in the terminal to your project folder. This lets you work inside that folder where your Django project files are. Replace 'myproject' with the name that you used.

    SHELL

    Copied!

    
cd myproject
  7. Once you are inside the folder containing manage.py (usually the project root), you can start the Django development server.

    SHELL

    Copied!

    
python manage.py runserver

Django Database Management and Migrations

  1. Detect model changes and prepare migration scripts.

    SHELL

    Copied!

    
python manage.py makemigrations
  2. Check what migrations will be created (Optional) useful for debugging.

    SHELL

    Copied!

    
python manage.py makemigrations --dry-run
  3. Update the database schema based on migration files.

    SHELL

    Copied!

    
python manage.py migrate
  4. View which migrations have been applied or are pending.

    SHELL

    Copied!

    
python manage.py showmigrations
